# quest-sonar: звуковой сонар для слепых на Quest 3

Unity-приложение для Meta Quest 3: датчик глубины (Meta Depth API) → карта препятствий вокруг пользователя → пространственные звуки и вибрация контроллеров. Дополнение к трости или собаке-проводнику, а не замена.

## Ветки и версии

| Ветка / тег | Что | Состояние |
|---|---|---|
| `main`, тег `v1-stable` | **Стабильная версия (v1):** лучи `EnvironmentRaycastManager`, облако точек частицами, звуковой сонар | проверена на шлеме, работает |
| `dev`, тег `v2-depth-gpu` | **Экспериментальная v2:** чтение текстуры глубины compute-шейдером (тысячи точек в кадр), GPU-облако точек | на шлеме комната «уезжает» в стороны при движении головы, идёт отладка |
| `stable/v1-audio-sonar`, тег `v1-audio-sonar` | исходная v1 до чистки кода | архив |

## Как взять

```bash
git clone https://github.com/Anikor/quest-sonar.git            # стабильная v1 (ветка main)
git clone -b dev https://github.com/Anikor/quest-sonar.git     # экспериментальная v2
```

Содержимое `Assets/` скопировать в Unity-проект с Meta XR Core SDK и MRUK (Unity 2022.3 или новее). Скрипты создают свои объекты сами при старте сцены, вешать ничего не нужно.

Подробности: `PROJECT_OVERVIEW.md` (в каждой ветке описана её версия); план и история работ по v2: `DEPTH_GPU_PLAN.md` (ветка `dev`).
