# quest-sonar: звуковой сонар для слепых на Quest 3

Unity-приложение для Meta Quest 3: датчик глубины (Meta Depth API) → карта препятствий вокруг пользователя → пространственные звуки; камера passthrough → чтение табличек вслух и распознавание дверей. Дополнение к трости или собаке-проводнику, а не замена.

## Ветки и версии

## Как взять

```bash
git clone -b vision https://github.com/Anikor/quest-sonar.git     # зрение: таблички, двери, режимы (самая полная)
git clone https://github.com/Anikor/quest-sonar.git               # стабильная v4.0 (ветка main)
git clone -b sound  https://github.com/Anikor/quest-sonar.git     # ветка звука
```

Проект: Unity **2022.3.62f3**, Meta XR SDK **201.0.0** (`com.meta.xr.sdk.all` с Asset Store или по отдельности из реестра
`https://npm.developer.oculus.com`, см. `tools/build/manifest-this-pc.json`), Meta XR Audio SDK 85.0.0, **Unity Sentis 2.1.3**
(нейросеть дверей). В репозитории `Assets/` и `Packages/`; папки `ProjectSettings/` нет: на ПК без неё всё нужное
выставляет `Assets/Editor/BuildQuest.cs` (сборка APK одной командой, см. `tools/build/README.md`).

### Что нужно на шлеме (ветка `vision`)
- Quest 3 / 3S, Horizon OS v74+ (камера passthrough). При первом запуске разрешить доступ к камере.
- Голос: движок **eSpeak NG** (F-Droid, `com.reecedunn.espeak`) установить и назначить по умолчанию - системный TTS Quest
  сторонним приложениям не работает. Команды в `VISION.md`.
- Комнату размечать в Space Setup не обязательно (двери из модели комнаты выключены: якорь стоял не там).

## Управление (ветка `vision`)

| Кнопка | Действие |
|---|---|
| Левый стик вправо / влево (держать 0.3 с) | следующий / предыдущий режим: навигация → только опасность → текст → ориентиры → узкий проход → тишина → эксперимент (короткий тон, без голоса) |
| Левый стик нажать | назвать текущий режим (вне режима «Эксперимент») |
| Правый курок | действие режима: «текст» - прочитать то, что перед тобой; «ориентиры» - ближайшая дверь, сторона и расстояние |
| Правый хват | прочитать вслух весь текст в кадре (в любом режиме) |
| X | открыть / закрыть панель порогов; правый стик ↑↓ параметр, ←→ значение, нажать - по умолчанию |
| B / Y | passthrough (облако точек) |
| Левый хват | `DepthSampler`: поза камеры глубины из глаза / из матрицы (отладка) |
| Стики и курки в режиме «Эксперимент» | как в `ExperimentController`: условие, столкновение, ложная тревога, конец попытки |

Вибрация контроллеров выключена (`ControllerVibrationOff`); голос звучит только для результатов (текст таблички, дверь),
не для меню.

## Как работают вместе ветки `sound` и `vision`

Граница - файл `Assets/SonarLandmarks.cs` (реестр ориентиров) и голос:

- **`vision` сообщает** ориентиры: `SonarLandmarks.Report(id, LandmarkKind.Door | Text, мировая_точка, текст)`
  и говорит через `SpeechOutput` (общий TTS, он же `SonarLandmarks.SpeakHandler`).
- **`sound` озвучивает** то, что лежит в `SonarLandmarks.All` (`AudioSonar.UpdateLandmarks`).
- Правило: `vision` не меняет `AudioSonar.cs` и `ExperimentController.cs` (все настройки режимов идут через их публичные
  поля), `sound` не меняет `Assets/Vision/` и `Assets/Modes/`. В `ObstacleMap.cs` ветка `vision` добавила только
  `QueryCell` и `mapMarks`.
